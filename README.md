# Smart Retail Intelligence

A retail data analytics project using Python, MySQL, and Power BI to understand sales performance, customer behaviour, and product trends.

## Project Overview

This project analyses the Online Retail dataset to identify business insights from retail transactions. Python is used for data inspection, cleaning, and analysis. MySQL is used to store the data, and Power BI is used to build dashboards.

## Tools & Technologies

- **Python:** Pandas, data cleaning, and analysis
- **MySQL:** Database and data loading
- **Power BI:** Interactive dashboards and business insights
- **GitHub:** Project code and documentation

## Project Workflow

1. Inspected the retail dataset and checked data quality.
2. Cleaned the data and handled invalid or missing records.
3. Analysed monthly revenue, transactions, and top-selling products.
4. Performed customer segmentation and RFM analysis.
5. Loaded retail data into MySQL.
6. Created Power BI dashboards to present business insights.

## Key Findings

- Original dataset: 541,909 rows.
- Cleaned dataset: 401,604 rows.
- Rows removed during cleaning: 140,305.
- Cancelled transactions identified: 8,872 rows.
- Unique cancelled invoices identified: 3,654.

## Project Files

- `day1_inspection.py` — Dataset inspection
- `day2_*.py` — Transaction, monthly revenue, customer, and product analysis
- `day3_*.py` — Customer segmentation and RFM analysis
- `day4_load_mysql.py` — MySQL data loading

## Power BI Dashboard

The Power BI report is included in this repository as a `.pbix` file. Download it and open it using Power BI Desktop to explore the report.

## Project Goal

To transform raw retail transaction data into useful business insights that support sales analysis, product performance tracking, and customer understanding.
